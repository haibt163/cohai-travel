# Visual modernization

This pass modernizes the presentation layer across the travel experience while leaving booking, auth, inventory, routing and domain rules unchanged.

## Scope
- global design tokens, surfaces, motion and form controls
- global header/footer and page-header treatment
- journey discovery and destination/stay/car browsing cards
- tour and stay detail layouts with sticky booking panels
- booking form presentation only
- search experience and bilingual presentation

The change is intentionally limited to UI composition and styling; booking and data behavior remain on the existing implementation.
